# Как сбилдить докер контейнер
### Для этого скачиваем репозиторий и распаковываем в удобную папку, затем (сначала нужно конечно же скачать Docker Desktop) открываем терминал, делаем cd в папку с таском и прописываем 'docker-compose up --build' этой командой мы одновременно и сбилдили и запустили репозиторий. А дальше перереходим либо по ссылке из Docker Desktop, либо на localhost:порт порт контейнера указан в docker-compose.yml в файлах таска
