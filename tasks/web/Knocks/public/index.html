Полигон HTTP‑испытаний

Добро пожаловать. Сервер хранит секрет, но не отдаёт его сразу.

Единственная интересующая вас точка входа — /flag. Флаг был разделён на три части и охраняется древним HTTP‑ритуалом.

Как получить части флага

1️⃣ Первая часть

Отправьте POST‑запрос на /flag.

2️⃣ Вторая часть

Используя ту же сессию, отправьте GET‑запрос на /flag.

3️⃣ Третья часть

Снова отправьте POST‑запрос на /flag с любыми параметрами (JSON, form‑data, query — не имеет значения).

🏁 Сборка флага

Соедините все части строго в том порядке, в котором вы их получили.

Примечание:
• Порядок запросов имеет значение • Сервер запоминает вас • Неверный метод — неверный результат
