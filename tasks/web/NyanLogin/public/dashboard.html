Техническая информация

JWT (JSON Web Token) состоит из трех частей, разделенных точками: header.payload.signature.
Header определяет алгоритм подписи, payload содержит данные пользователя, signature проверяет целостность токена.
Для изменения payload требуется правильная подпись с использованием секретного ключа.
